# Assignment Tracker

## Project Name
**Assignment Tracker** is a simple and modern web application that helps students manage their assignments, deadlines, and priorities in one place.

## Features
- User registration form
- User login form
- Add new assignments
- View all assignments
- Mark assignments as completed
- Delete assignments
- Store data using **localStorage**
- Clean and responsive UI design
- Contact form for user messages

## Introduction
Assignment Tracker is built for students who want an easy way to organize their academic tasks. Users can create an account, log in, add assignments with subject, title, description, deadline, and priority, then manage them from a simple dashboard interface.

The project is designed using **HTML**, **CSS**, and **JavaScript**, and it stores data locally in the browser using **localStorage**.

## How to Run the Project
1. Download or clone the project files.
2. Make sure all files are in the same folder:
   - `index.html`
   - `assignments.html`
   - `register.html`
   - `login.html`
   - `contact.html`
   - `style.css`
   - `main.js`
3. Open the project folder.
4. Double-click `index.html` to open it in your browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- localStorage

## Notes
- This project does not use a backend database.
- All user and assignment data are stored in the browser.
- Best for learning and small frontend practice projects.
